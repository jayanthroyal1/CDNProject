# Packages installed

# Runtime Packages

# Authentication Packages

# Logging Package

| helmet       | Security headers |
| compression  | Gzip             |
| morgan       | Request logs     |
| winston      | Application logs |
| dotenv       | Env vars         |
| zod          | Validation       |
| jsonwebtoken | JWT              |
| bcryptjs     | Password hashing |
